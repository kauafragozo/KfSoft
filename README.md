<h2>🏛️ Arquitetura </h2>
A arquitetura do projeto é separada em três seções: <br>
1. Console: Responsável por controlar o fluxo de execução do programa. <br>
2. Domain: Armazena as entidades e suas dependencias .<br>
3. EfCore: Responsavel por mapear e  interagir com o banco de dados, além de armazenar a string de conexão em um arquivo isolado.
